# Registro de Refinamento

## Versão inicial
A especificação definiu criação, consulta, listagem e conclusão de tarefas.

## Refinamentos
- O título passou a ter validação de tamanho mínimo de 1 caractere.
- Foi incluído um endpoint `/health` para facilitar a validação do ambiente.
- Foram incluídos casos de borda para tarefa inexistente e título vazio.
